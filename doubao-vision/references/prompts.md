# 提示词模板

按任务复制并改写，把 `{...}` 替换成实际内容。精细判断务必配合裁剪放大：原图坐标用 `-Crop`，模型视图坐标用 `-CropView`。

## 0. 通用识图（默认场景）

```text
请仔细分析这张图片，用中文回答：1) 图片里主要是什么（物体/场景/人物/文字）；2) 有哪些值得注意的细节；3) 如果图中有文字，请完整读出。
```

## 1. 星空照片整体 QA

```text
请以风光摄影师的身份分析这张星空照片，用 JSON 返回：
{
  "构图": "一句话点评",
  "星点锐度": "清晰 / 轻微模糊 / 明显拖线",
  "噪点水平": "低 / 中 / 高，并说明主要分布（暗部/天空）",
  "暗部细节": "一句话描述",
  "光晕或紫边": "无 / 轻微 / 明显，出现在哪里",
  "整体曝光": "欠曝 / 正常 / 过曝",
  "建议": ["不超过3条可操作的调整建议"]
}
```

## 2. 局部放大检查（配 -Crop x,y,w,h）

```text
这是同一张星空照片的局部放大图。请重点检查：
1. 星点是否接近圆形，有无拖线或拉线；
2. 噪点颗粒的大小和颜色（彩噪/亮度噪点）；
3. 星点周围有无光晕、色差或锐化过度。
用 JSON 返回 {"星点": "...", "噪点": "...", "光晕/色差": "...", "结论": "合格/需要处理"}
```

## 3. GUI 截图定位（配 -Screenshot）

```text
这是 [Photoshop/其他应用] 的截图。你看到的图片尺寸是 {视图尺寸 WxH，以脚本输出的"视图尺寸"为准}。请找到以下元素并用 JSON 返回每个元素的中心坐标 (x,y) 和边界框 (width,height)：
元素清单：[曲线调整面板、曝光滑块、缩放工具、图层面板...]
返回格式：{"元素名": {"x": 0, "y": 0, "width": 0, "height": 0}}
坐标以图片左上角为原点，按视图尺寸返回。找不到的元素返回 null。
拿到结果后用 -CropView 传入坐标做放大检查，脚本会自动换算回原图坐标。
```

## 3b. 多图对比（配 -Images a.jpg,b.jpg）

```text
这是同一场景的两张图片（图1 在前，图2 在后）。请用 JSON 对比：
{"主体变化":"...", "曝光差异":"...", "色彩差异":"...", "清晰度差异":"...", "哪张更好":"图1 / 图2 / 各有优劣", "理由":"一句话"}
```

## 4. 直方图分析

```text
这是照片的直方图。请用 JSON 判断：
{"黑场": "有/无溢出", "白场": "有/无溢出", "主峰位置": "偏左/居中/偏右",
 "动态范围": "窄/正常/宽", "曝光倾向": "欠曝/正常/过曝", "备注": "..."}
```

## 5. 通用描述

```text
请客观描述这张图片：主要物体/场景、光线、颜色、清晰度、以及任何明显瑕疵或异常。200 字以内。
```

## 校准建议

正式使用前，用同一组问题分别问一张"满意成片"和一张"问题片"，确认模型给出的判断能区分两者，再把它当正式 QA 依据。
